Free, open-source Minecraft tools.

GamerXD_GZ Launcher

An idea for a free, open-source third-party Minecraft Java launcher, with legitimate Microsoft authentication and official game downloads — no cracked or offline auth, no ads. Still just a concept, and it may not end up happening.

PlatformWindows, Linux, Chromebook
AuthenticationOfficial Microsoft sign-in
Game filesOfficial downloads
LicenseFree & open-source
StatusIdea stage — not confirmed
In development

FKAS AntiCheat & GZAC

Two server-side anti-cheat plugins, built for different server generations — a modern Paper build and a legacy Spigot build — so small survival and SMP servers can catch common cheats without running something heavy.

FKAS AntiCheatPaper 1.20.4
GZACSpigot 1.12.2
TypeServer-side plugin
StatusIn development
In development

GamerXD Client

A lightweight, browser-based Minecraft-style client, built for modern browsers and optimized to run smoothly on Chromebooks and other low-end devices. Original UI, no copied code or Mojang-owned assets, and static-hostable with no server to maintain.

Runs inModern browsers (WebGL/Wasm)
Optimized forChromebooks, low-end devices
HostingStatic — GitHub / Cloudflare Pages
LicenseMIT
